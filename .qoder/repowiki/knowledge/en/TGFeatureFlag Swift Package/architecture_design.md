Package.swift declares one public library product `TGFeatureFlag` (target `TGFeatureFlag`) plus a sibling test target, targeting iOS 17+, macOS 14+, tvOS 17+, and watchOS 10+; all four child modules (`core`, `providers`, `swiftui_integration`, `example_app`) are grouped under this package so consumers import a single module. The children compose through a fixed contract: `core` defines `FeatureFlagKey`/`FeatureFlagProvider`/`AsyncFeatureFlagProvider`/`GroupedFeatureFlag` protocols and the `@MainActor @Observable FeatureFlagService`; `providers` implements concrete providers (Debug, Local, UserDefaults, Rollout) that plug into that service; `swiftui_integration` exposes the service via `@Environment` and a `FeatureGate` view; `example_app` is the only consumer that wires providers into the service at app launch. The priority chain (Debug > UserDefaults > Local Default) is the cross-child runtime contract that every provider must honor. Priorities support numeric customization via `.custom(Int)` alongside `.highest` and `.lowest` for explicit chain ordering.
